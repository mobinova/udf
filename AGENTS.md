# Repository instructions

- Never create a Git commit or push changes unless the user explicitly asks for that action.
- Keep work local until the user explicitly authorizes publishing or pushing.
- Do not upload UDF files or their extracted contents to third-party services. Treat them as confidential legal documents and process them locally.
- Preserve every source `.udf` file. A generated PDF is a convenience copy and does not replace or carry the source document's electronic signature.
- Do not run code or tests unless the user asks for execution or verification.
